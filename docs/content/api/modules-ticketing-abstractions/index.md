[Back to package index](../index.md)

## Description

Ticketing module contracts and DTOs for tickets, comments, categories, attachments, status, and priority. Use it with the surrounding package APIs when composing application code.

## Install

```shell
dotnet add package KamiSama.Modules.Ticketing.Abstractions --version 10.0.10
```
