# KamiSama.Extensions.Xml

[Back to package index](../index.md)

Version: `10.0.10`

## Description

XML serialization and deserialization helpers for files, streams, strings, and byte arrays. Use it when application code needs simple XML persistence or transport helpers.

## Install

```shell
dotnet add package KamiSama.Extensions.Xml --version 10.0.10
```
