# KamiSama.Extensions.WebModules

[Back to package index](../index.md)

Version: `10.0.10`

## Description

Modular ASP.NET Core application builder helpers for registering services and applying middleware through reusable web modules. Use it with the surrounding package APIs when composing application code.

## Install

```shell
dotnet add package KamiSama.Extensions.WebModules --version 10.0.10
```
