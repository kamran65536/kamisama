# KamiSama.Extensions.Json

[Back to package index](../index.md)

Version: `10.0.10`

## Description

JSON serialization and deserialization helpers for files, streams, byte arrays, and strings. Use it when application code needs compact System.Text.Json convenience methods.

## Install

```shell
dotnet add package KamiSama.Extensions.Json --version 10.0.10
```
