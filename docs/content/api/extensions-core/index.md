# KamiSama.Extensions.Core

[Back to package index](../index.md)

Version: `10.0.10`

## Description

Core extension methods and paging models for common .NET tasks such as bytes, hex, base64, hashes, dates, streams, arrays, queues, and IQueryable paging. Use it with the surrounding package APIs when composing application code.

## Install

```shell
dotnet add package KamiSama.Extensions.Core --version 10.0.10
```
