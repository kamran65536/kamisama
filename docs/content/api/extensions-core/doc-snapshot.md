## Description

Common .NET extension methods for byte and string conversion, hashing, symmetric and RSA cryptography, Persian dates, streams, arrays, queues, logging, and TimeSpan creation.
Also includes lightweight paging records and an `IQueryable<T>` helper for producing paged results.

## How to use

```shell
dotnet add package KamiSama.Extensions.Core --version 10.0.0
```
