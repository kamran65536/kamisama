## Description

Provides fluent numeric extensions for constructing `TimeSpan` values in common units. Both integer and fractional values are supported.

## Declaration

```csharp
public static class TimeSpanExtensions
```

## Example

```csharp
TimeSpan timeout = 30.Seconds();
TimeSpan interval = 1.5.Minutes();
```
