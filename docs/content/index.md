# KamiSama.Extensions

KamiSama.Extensions is a reusable .NET and ASP.NET Core package family for building modular applications. It includes core extension methods, dependency-injection helpers, JSON/XML serialization utilities, repository implementations, HTTP exception handling, ProblemDetails integration, web modules, external service integrations, and ready-made bounded-context modules such as Identity, Localization, Locations, ServicePlans, and Ticketing.

Use these packages when you want shared infrastructure, feature-layer building blocks, and module wiring patterns across multiple services without copying the same plumbing into every project.

Version: `10.0.11.9`

## Package areas

| Area | What it provides |
| --- | --- |
| Core extensions | Byte, string, date, hash, stream, collection, conversion, and paging helpers. |
| Dependency injection | Attribute-based service registration and assembly scanning. |
| Serialization | JSON and XML helpers for strings, streams, bytes, files, and repositories. |
| Repositories | In-memory, JSON, XML, EF, and EF Core repository patterns and paging support. |
| Chassis | Base classes and contracts for CRUD-style feature services and HTTP-aware errors. |
| Web modules | Modular ASP.NET Core service and middleware registration. |
| External services | Email and SMS abstractions plus SMTP, Kavenegar, and NeoZarin integrations. |
| Application modules | Identity, Localization, Locations, ServicePlans, and Ticketing bounded contexts. |
| Solution design and templates | Modular YAML design, AI-ready solution maps, project-family scaffolds, CRUD vertical slices, providers, servers, and Aspire helpers. |

## Packages

- [KamiSama.Chassis.Commons](api/chassis-commons/index.md) - Reusable feature and repository base classes for common CRUD-style application flows. Use this package when building service-layer features around entities, DTOs, repositories, and paged results.
- [KamiSama.Chassis.Commons.Abstractions](api/chassis-commons-abstractions/index.md) - Feature and repository contracts for the KamiSama chassis layer. Reference this package from application or module projects that need to depend on abstractions instead of concrete implementations.
- [KamiSama.Chassis.HttpExceptions](api/chassis-httpexceptions/index.md) - HTTP-oriented exception types with status codes, localization keys, and extra problem details. Use these exceptions to keep application errors consistent across ASP.NET Core APIs.
- [KamiSama.Chassis.ProblemDetails](api/chassis-problemdetails/index.md) - ASP.NET Core ProblemDetails integration for converting KamiSama HTTP exceptions into standardized API error responses.
- [KamiSama.Extensions.Core](api/extensions-core/index.md) - Common .NET extension methods for byte and string conversion, hashing, symmetric and RSA cryptography, Persian dates, streams, arrays, queues, logging, and TimeSpan creation. Also includes lightweight paging records and an IQueryable<T> helper for producing paged results.
- [KamiSama.Extensions.DependencyInjection](api/extensions-dependencyinjection/index.md) - Automatically register attributed service implementations with Microsoft.Extensions.DependencyInjection by scanning selected assemblies. Choose transient, scoped, or singleton lifetimes, keyed or unkeyed registrations, explicit or inferred service types, and single or multiple registrations.
- [KamiSama.Extensions.Json](api/extensions-json/index.md) - System.Text.Json convenience extensions for serialization, deserialization, dynamic JSON object graphs, and converter registration. Includes converters for BigInteger, hexadecimal byte arrays, TimeSpan, and discriminator-based polymorphic types.
- [KamiSama.Extensions.Logging](api/extensions-logging/index.md) - Trace method entry through Microsoft.Extensions.Logging without repeating caller names. LogMethodEntry emits a Trace event containing the inferred calling type and member name and can include selected argument values for diagnostics.
- [KamiSama.Extensions.NLog](api/extensions-nlog/index.md) - Provides three NLog layout renderers for Persian-calendar timestamps and an IFileCompressor implementation for creating password-protected ZIP archives through SharpZipLib.
- [KamiSama.Extensions.RestSharp](api/extensions-restsharp/index.md) - Fluent RestSharp request construction and dependency injection registration for HTTP integrations. Build GET, POST, PUT, and DELETE requests with parameters, headers, URL segments, files, or JSON bodies, then deserialize successful responses.
- [KamiSama.Extensions.Xml](api/extensions-xml/index.md) - Serialize objects to XML strings and deserialize XML strings using configurable XmlSerializer and XmlWriterSettings instances. Build attribute-driven XmlAttributeOverrides for polymorphic elements and array items.
- [KamiSama.IranSystem](api/iransystem/index.md) - Iran System encoding conversion helpers for legacy Persian text interoperability. Use this package when integrating with systems that still exchange Iran System encoded data.
- [KamiSama.Testing.NSubstitute](api/testing-nsubstitute/index.md) - A DI-first test builder that registers configured substitutes and creates NSubstitute doubles for missing constructor dependencies. Use it to build focused service tests through a scoped Microsoft.Extensions.DependencyInjection container.
- [KamiSama.Modules](api/modules/index.md) - Composable ASP.NET Core modules that register services before application build and apply middleware or endpoints afterward. Use this package to assemble startup behavior in explicit module order through `ExtendedWebApplicationBuilder`.
- [KamiSama.ExternalServices.Exceptions](api/externalservices-exceptions/index.md) - HTTP-oriented exceptions for external-service discovery failures, timeouts, and invalid provider responses. Use them at integration boundaries to expose consistent localization keys, arguments, and 500 or 504 status codes.
- [KamiSama.ExternalServices.Email.Abstractions](api/externalservices-email-abstractions/index.md) - Provider-neutral contract and request model for sending email through KamiSama external-service implementations. Reference it from callers and providers that need to exchange recipient, subject, body, and HTML-format data without depending on SMTP or another transport.
- [KamiSama.ExternalServices.Email.Core](api/externalservices-email-core/index.md) - Provider-selecting email registration for ASP.NET Core applications, including default-provider options and a built-in mock provider. Use it to route `ISendEmail` calls to keyed transport implementations.
- [KamiSama.ExternalServices.Email.Smtp](api/externalservices-email-smtp/index.md) - SMTP transport registration and configuration for KamiSama email services. The current implementation contains a known inverted validation defect that rejects complete SMTP settings before sending.
- [KamiSama.ExternalServices.Sms.Abstractions](api/externalservices-sms-abstractions/index.md) - Provider-neutral SMS sending contracts and request data. This package contains abstractions only and does not send messages or register an SMS provider.
- [KamiSama.ExternalServices.Sms.Core](api/externalservices-sms-core/index.md) - Provider-selecting SMS registration for ASP.NET Core applications, including default-provider options and a scoped mock provider. Use it to route unkeyed `ISendSms` calls to scoped keyed providers.
- [KamiSama.ExternalServices.Sms.Kavenegar](api/externalservices-sms-kavenegar/index.md) - Scoped Kavenegar SMS provider registration and configuration for KamiSama SMS services. The current sender contains a known inverted validation defect that rejects a configured API key before sending.
- [KamiSama.ExternalServices.Sms.NeoZarin](api/externalservices-sms-neozarin/index.md) - Scoped NeoZarin HTTP SMS provider registration and configuration for KamiSama SMS services. It requires KamiSama RestSharp and `AddHttpClient`, and the current sender contains a known inverted validation defect.
- [KamiSama.Modules.Identity.Abstractions](api/modules-identity-abstractions/index.md) - Provider-neutral Identity feature contracts, requests, responses, search models, role constants, and failure metadata for login, token refresh, logout, user, role, password, session, and two-factor workflows. Reference this package from callers or alternative implementations that should not depend on ASP.NET Core Identity, Entity Framework Core, or a database provider.
- [KamiSama.Modules.Identity.Core](api/modules-identity-core/index.md) - ASP.NET Core Identity implementation for KamiSama login, token refresh, logout, user, role, password, two-factor, and session feature contracts, with revocable JWT sessions, EF Core persistence, mappings, and modular startup registration. Install it with exactly one Identity database provider and review the documented security and runtime limitations before exposing its features.
- [KamiSama.Modules.Identity.Postgresql](api/modules-identity-postgresql/index.md) - PostgreSQL EF Core provider registration for KamiSama.Modules.Identity.Core. Install it in an Identity host and select the required provider callback so the module can resolve its database context and run startup migrations.
- [KamiSama.Modules.Identity.Sqlite](api/modules-identity-sqlite/index.md) - SQLite EF Core provider registration for KamiSama.Modules.Identity.Core. Install it in an Identity host and select the required provider callback so the module can resolve its database context and run startup migrations.
- [KamiSama.Modules.Localization.Abstractions](api/modules-localization-abstractions/index.md) - Provider-neutral localization feature contracts and culture metadata for listing, reading, and selecting application cultures. Reference this package when callers or implementations should not depend on the ASP.NET Core localization module.
- [KamiSama.Modules.Localization.Core](api/modules-localization-core/index.md) - ASP.NET Core localization registration and scoped features for configured culture discovery, current-culture lookup, and culture-selection cookies. Use it to bind localization settings and compose request localization through `KamiSama.Modules`.
- [KamiSama.Modules.Locations.Abstractions](api/modules-locations-abstractions/index.md) - Provider-neutral province and city feature contracts, requests, DTOs, and paging search models. Reference this package from callers or alternative implementations that should not depend on EF Core, ASP.NET Core module setup, or a database provider.
- [KamiSama.Modules.Locations.Core](api/modules-locations-core/index.md) - ASP.NET Core Locations implementation with EF Core province and city persistence, scoped feature services, modular registration, and startup database initialization. Install it with at least the selected PostgreSQL or SQLite provider and complete setup through the extended builder.
- [KamiSama.Modules.Locations.Postgresql](api/modules-locations-postgresql/index.md) - PostgreSQL EF Core context and provider registration for KamiSama.Modules.Locations.Core, including Locations migrations and keyed context resolution. Select it from the Core provider callback when the configured database provider is `postgresql`.
- [KamiSama.Modules.Locations.Sqlite](api/modules-locations-sqlite/index.md) - SQLite EF Core context and provider registration for KamiSama.Modules.Locations.Core, including Locations migrations and keyed context resolution. Select it from the Core provider callback when the configured database provider is `sqlite`.
- [KamiSama.Modules.PolicyEngine.Abstractions](api/modules-policyengine-abstractions/index.md) - Provider-neutral CRUD contracts, DTOs, search models, and evaluation-shaped data for policy definitions. It intentionally provides no evaluator, condition parser, action execution, transport, or authorization integration.
- [KamiSama.Modules.PolicyEngine.Core](api/modules-policyengine-core/index.md) - EF Core data management for policy actions, rules, lists, and their relationships, with scoped CRUD features and modular startup registration. Install one provider, provision the schema separately, and supply evaluation and authorization in the host.
- [KamiSama.Modules.PolicyEngine.Postgresql](api/modules-policyengine-postgresql/index.md) - PostgreSQL EF Core context registration for PolicyEngine Core under the `postgresql` provider key. It configures Npgsql and lazy loading but currently ships no PolicyEngine migrations.
- [KamiSama.Modules.PolicyEngine.Sqlite](api/modules-policyengine-sqlite/index.md) - SQLite EF Core context registration for PolicyEngine Core under the `sqlite` provider key. It configures SQLite and lazy loading but currently ships no PolicyEngine migrations.
- [KamiSama.Modules.ServicePlans.Abstractions](api/modules-serviceplans-abstractions/index.md) - Provider-neutral ServicePlans feature contracts, requests, DTOs, search models, and subscription data types. Reference this package from callers or alternative implementations that should not depend on EF Core, ASP.NET Core module setup, or a database provider.
- [KamiSama.Modules.ServicePlans.Core](api/modules-serviceplans-core/index.md) - ASP.NET Core ServicePlans implementation with EF Core plan, offer, subscriber, and subscription entities, scoped CRUD features, modular registration, and startup initialization. Install one provider, provision the schema separately, and enforce authorization and domain validation in the host.
- [KamiSama.Modules.ServicePlans.Postgresql](api/modules-serviceplans-postgresql/index.md) - PostgreSQL EF Core context registration for ServicePlans Core under the `postgresql` provider key. It configures Npgsql and lazy loading but currently ships no ServicePlans migrations.
- [KamiSama.Modules.ServicePlans.Sqlite](api/modules-serviceplans-sqlite/index.md) - SQLite EF Core context registration for ServicePlans Core under the `sqlite` provider key. It configures SQLite and lazy loading but currently ships no ServicePlans migrations.
- [KamiSama.ServicePlans.PolicyAction](api/serviceplans-policyaction/index.md) - ASP.NET Core registration and contracts for a ServicePlans-oriented handler over PolicyEngine contexts. The registered handler is currently unimplemented, and the package does not dispatch resolved actions or call ServicePlans features.
- [KamiSama.Modules.Ticketing.Abstractions](api/modules-ticketing-abstractions/index.md) - Provider-neutral Ticketing feature contracts, requests, DTOs, search models, statuses, priorities, and comment sides. Reference this package from callers or alternative implementations that should not depend on EF Core, ASP.NET Core module setup, or a database provider.
- [KamiSama.Modules.Ticketing.Core](api/modules-ticketing-core/index.md) - ASP.NET Core Ticketing implementation with EF Core entities, validated ticket workflows, repositories, scoped features, modular registration, and startup database initialization. Install it with at least the selected PostgreSQL or SQLite provider and review the documented registration and authorization limitations before exposing its features.
- [KamiSama.Modules.Ticketing.Postgresql](api/modules-ticketing-postgresql/index.md) - PostgreSQL EF Core context and provider registration for KamiSama.Modules.Ticketing.Core, including Ticketing migrations and keyed context resolution. Select it from the Core provider callback when the configured database provider is `postgresql`.
- [KamiSama.Modules.Ticketing.Sqlite](api/modules-ticketing-sqlite/index.md) - SQLite EF Core context and provider registration for KamiSama.Modules.Ticketing.Core, including Ticketing migrations and keyed context resolution. Select it from the Core provider callback when the configured database provider is `sqlite`.
- [KamiSama.Repositories.Core](api/repositories-core/index.md) - Repository contracts, an in-memory implementation, connection-string options, and database initialization abstractions. Use it to keep callers independent of persistence or to hold transient entities in tests and lightweight processes.
- [KamiSama.Repositories.EntityFramework](api/repositories-entityframework/index.md) - Entity Framework 6 repositories with immediate persistence and ordered-query paging. Use this package to expose tracked EF6 queries through KamiSama repository contracts and produce paged UI or API results.
- [KamiSama.Repositories.EntityFrameworkCore](api/repositories-entityframeworkcore/index.md) - Entity Framework Core repositories, paging, database initialization, and multi-provider DbContext registration. Use it for tracked repository access, migration and seed workflows, or configuration-selected provider contexts.
- [KamiSama.Repositories.EntityFrameworkCore.Postgresql](api/repositories-entityframeworkcore-postgresql/index.md) - PostgreSQL registration for KamiSama multi-provider Entity Framework Core DbContexts. It adds scoped keyed context resolution, lazy-loading proxies, migration-history configuration, and process-wide Npgsql compatibility switches.
- [KamiSama.Repositories.EntityFrameworkCore.Sqlite](api/repositories-entityframeworkcore-sqlite/index.md) - SQLite registration for KamiSama multi-provider Entity Framework Core DbContexts. It adds scoped keyed context resolution, lazy-loading proxies, and migration-history configuration.
- [KamiSama.Repositories.Json](api/repositories-json/index.md) - Lazy-loading JSON file repository with synchronous and asynchronous query and mutation APIs. It caches entities in memory and rewrites an existing JSON array file after each mutation, with important failure, atomicity, and concurrency limitations.
- [KamiSama.Repositories.Xml](api/repositories-xml/index.md) - Read-oriented XML directory repositories that load one entity per file into memory. Version 10.0.0 has an incompatible default serializer and a broken mutation path, so use these types only for reads with an explicit per-entity serializer.
- [KamiSama.Templates](api/templates/index.md) - Eleven composable solution, project-family, and item templates for AI-ready KamiSama solution design, bounded contexts, providers, ordered Bootstrap composition, unified servers, CRUD, panel UI, Aspire helpers, and confirmed delete actions.
